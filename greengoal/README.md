# الأخبار الرياضية ومباريات اليوم – greengoal.net

نشر تلقائي لأخبار كرة القدم ومباريات اليوم ونتائجها على موقع **Green Goal Arena** (www.greengoal.net).

## كيف تعمل
1. المهمة اليومية في Claude «Green Goal: مباريات اليوم والأخبار الرياضية» تعمل 3 مرات يومياً بتوقيت بيروت:
   - **8:41 صباحاً**: مباريات اليوم (ملف جديد) + 3 إلى 6 أخبار رياضية.
   - **6:41 مساءً**: تحديث نتائج المباريات التي انتهت أو الجارية + خبر عاجل إن وُجد.
   - **12:41 بعد منتصف الليل**: النتائج النهائية لمباريات اليوم السابق (`"final": true`).
2. المهمة ترفع الملفات إلى `greengoal/`، والرفع يشغّل `.github/workflows/greengoal.yml` الذي يصمّم الأغلفة وينشر على بلوغر بمفاتيح بلوغر نفسها المستعملة للدليل.
3. **تدوينة واحدة لكل يوم مباريات**: تُنشأ صباحاً ثم تُحدَّث (العنوان والنتائج والغلاف) في كل تشغيل، فلا تتكرر.
4. أول نشر آلي يُحفظ **مسودات** للمراجعة، وبعده نشر مباشر. الحالة في `state.json`.
5. ودجت «مباريات اليوم» في الصفحة الرئيسية (`site/greengoal-matches.html`) تقرأ `today.json` وتتحدّث كل 10 دقائق.

تشغيل يدوي من Actions ← «الأخبار الرياضية ومباريات اليوم» ← Run workflow: `check` لفحص الوصول، `draft` أو `publish` لفرض طريقة النشر.

## الوسوم (الأقسام على الموقع)
`بعلبك-الهرمل` (أندية وملاعب وبطولات المنطقة) · `محلية` (كرة القدم اللبنانية والمنتخب والدوري) · `دولية` (الدوريات والبطولات الكبرى). تدوينة المباريات تأخذ `مباريات اليوم` + وسوم الأقسام التي فيها مباريات.

## ملف المباريات `greengoal/matches/YYYY-MM-DD.json`
اسم الملف = تاريخ يوم المباريات بتوقيت بيروت (تشغيل منتصف الليل يحدّث ملف **الأمس**).
```json
{
  "date": "2026-11-23",
  "final": false,
  "updated": "18:41",
  "headline": "سطر اختياري لأبرز مباراة اليوم",
  "groups": [
    {"scope": "محلية", "competition": "الدوري اللبناني – الدرجة الأولى",
     "matches": [
       {"time": "14:30", "home": "النجمة", "away": "الأنصار", "status": "finished",
        "home_score": 2, "away_score": 1, "venue": "ملعب ...", "channel": "", "note": ""}
     ]}
  ],
  "sources": [{"name": "اسم المصدر", "url": "https://..."}]
}
```
- `scope`: `بعلبك-الهرمل` أو `محلية` أو `دولية`. ترتيب المجموعات حسب الأهمية داخل كل قسم.
- `status`: `upcoming` (لم تبدأ) · `live` (جارية، وفي `note` الدقيقة) · `finished` · `postponed` · `cancelled` · `unknown` (لم تتأكد النتيجة).
- `time` بصيغة `HH:MM` **بتوقيت بيروت** (حوّل من توقيت أوروبا: بيروت = CET + 1 ساعة في الشتاء).
- `finished` و`live` يجب أن يكون فيهما `home_score` و`away_score` (أرقام). ركلات الترجيح في `"penalties": "4-3"`.
- لا تخترع نتيجة أبداً: إن لم تتأكد من مصدرين (أو من المصدر الرسمي) اجعلها `unknown`.
- `"final": true` فقط في تشغيل منتصف الليل حين تنتهي كل المباريات.
- لا تحذف مباراة نُشرت صباحاً؛ حدّث حالتها فقط.

## ملفات كل خبر `greengoal/posts/YYYY-MM-DD-NN/`
- `meta.json`:
  ```json
  {
    "title": "عنوان الخبر كما يظهر على الموقع",
    "label": "دولية",
    "kicker": "دوري أبطال أوروبا",
    "cover_title": "عنوان قصير للغلاف (حتى 70 حرفاً)",
    "summary": "جملة افتتاحية واحدة تلخّص الخبر",
    "sources": [{"name": "اسم المصدر", "url": "https://..."}]
  }
  ```
- `post.html`: نص الخبر فقط (فقرات `<p>`، وعند الحاجة `<h3>` و`<ul>` و`<strong>`)، **من دون** `<h1>` أو `<style>` أو `<script>` أو صور. الغلاف والعنوان والملخّص والمصدر وزر المشاركة على واتساب وسطر الحجز تُضاف تلقائياً.

## قواعد كتابة الأخبار
- كرة القدم أولاً (ويُقبل خبر كبير من رياضة أخرى في لبنان أو بعلبك-الهرمل).
- 60 كلمة على الأقل، 120–250 كلمة عادةً، بكلماتك أنت لا نسخاً من المصدر. اقتباس واحد على الأكثر لكل مصدر وأقل من 15 كلمة.
- مصدر موثوق (الاتحاد اللبناني لكرة القدم، صفحات الأندية الرسمية، وكالات ووسائل إعلام معروفة). خبر من مصدر مجهول واحد لا يُنشر.
- لا سياسة، ولا إشكالات أو شغب أو خلافات بين أندية أو عائلات أو بلدات، ولا شائعات انتقالات غير مؤكدة، ولا ما يثير حساسية طائفية أو مناطقية.
- لا تكرّر خبراً نُشر سابقاً (راجع `state.json` → `posts`) إلا كمتابعة فيها جديد.
- لا جمل موجّهة إلى صاحب الموقع ولا ملاحظات عمل داخل الملفات.
- لهجة الجمهور اللبناني في المصطلحات («الدوري اللبناني»، «المنتخب اللبناني»)، وأسماء الأندية الأجنبية بالعربية كما تُكتب في الإعلام اللبناني.

## قبل الرفع
```bash
python3 scripts/greengoal.py validate          # يجب أن يطبع: كل الملفات سليمة
python3 scripts/greengoal.py build && python3 scripts/greengoal.py preview   # معاينة اختيارية
```
احذف الأغلفة المولّدة محلياً (`cover.png` و`matches/*.png` الجديدة) قبل الـcommit؛ GitHub يولّدها بنفسه.

## صفحة الدوري اللبناني (صفحة ثابتة) — `greengoal/league.json`
صفحة بلوغر ثابتة (`/p/lebanese-league.html`) تقرأ `greengoal/league.json` مباشرة من GitHub وتتحدّث وحدها
(كل 10 دقائق، وكل دقيقتين أثناء المباريات الجارية). **رفع league.json لا يشغّل أي workflow**: يكفي الـpush.
محتوى الصفحة نفسه في `site/greengoal-league-page.html`؛ تعديله ورفعه يحدّث الصفحة على بلوغر تلقائياً
(أو Actions ← mode = page).

```json
{
  "competition": "الدوري اللبناني لكرة القدم – الدرجة الأولى",
  "season": "2026-2027",
  "updated": "2026-11-23 19:30",
  "relegation": 0,
  "standings": [{"team": "جويا", "p": 7, "w": 5, "d": 1, "l": 1, "gf": 15, "ga": 2, "pts": 16}],
  "previous": {"title": "نتائج الأسبوع الماضي", "matches": [...]},
  "current":  {"title": "مباريات هذا الأسبوع", "matches": [...]},
  "sources": [{"name": "...", "url": "https://..."}]
}
```
- `standings` مرتّب كما في الترتيب الرسمي. يُفحص: فاز+تعادل+خسر = لعب، والنقاط = 3×فاز + تعادل (إن وُجد خصم نقاط رسمي ضع `"deducted": 3`).
- `relegation`: عدد الفرق الهابطة إن أعلنه الاتحاد (يلوّن آخر الجدول بالأحمر)، وإلا 0.
- المباراة: `date` (YYYY-MM-DD)، `time` (HH:MM **بتوقيت بيروت**)، `home`، `away`، `status` (upcoming/live/finished/postponed/cancelled/unknown)، `home_score`، `away_score`، `minute` للجارية، `venue` و`note` اختياريان.
- أسماء الفرق في المباريات يجب أن تطابق أسماء جدول الترتيب حرفياً (الفحص يرفض غير ذلك).
- `previous` = مباريات الأسبوع الماضي (من الإثنين إلى الأحد) بنتائجها، و`current` = مباريات هذا الأسبوع (من الإثنين إلى الأحد)، ومعها المؤجّلة المعاد جدولتها هذا الأسبوع. كل إثنين تنتقل مباريات `current` إلى `previous`.
- لا تخترع نتيجة أو موعداً: من مصدرين متطابقين أو من الاتحاد اللبناني لكرة القدم.
